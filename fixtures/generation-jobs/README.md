# GenerationJob synthetic template

`request.synthetic.template.json` is visibly synthetic, test-only input for the
local Wave D/D3 contract and ledger tooling. Its repeated digests are placeholders,
not hashes of real source, measurement, generator input, manifest, or GLB bytes.

The template is intentionally non-promotable. A valid job ledger can establish
deterministic processing history and can bind Proxy manifest/GLB evidence at the
`running -> review` boundary. It cannot approve, publish, deploy, recommend for
live use, create physical evidence, or establish G1, G2, or G3 PASS.
